# Meine ersten Schritte mit GitHub

Noch bin ich ziemlich verloren, aber ich verstehe zumindest schon mal den Sinn von GitHub. Ich habe schon oft Dateien von GitHub runtergeladen und es ist sehr interessant zu lernen was überhaupt hinter der Seite steckt. Im interaktiven Tutorial habe ich gelernt was ein Repository ist, wie man Commits und Branches erstellt und wie man Branches mit dem Main-Branch zusammenführt.

## Wichtige Git Begriffe

- **Repository:** Ein Projektordner, der alle Dateien und den Änderungsverlauf enthält.
- **Commit:** Ein Schritt im Projekt der mit einer Nachricht versehen ist, was geändert wurde.
- **Branch:** Ein ENtwicklungszweig der unabhängig vom Hauptstand läuft. Dient dazu um z.B was auszuprobieren ohne den Hauptstand zu ändern.
